# Pendências (ações humanas)

- Bucket "logos" foi criado PRIVADO porque a política do workspace bloqueia buckets públicos. O app funciona assim (a logo é salva com um link assinado de longa duração, ~10 anos). Opcional: se quiser bucket público, um admin do workspace deve habilitar "public buckets" em Settings → Privacy & Security.
- Acessar /primeiro-acesso imediatamente após a publicação para criar o super admin.
- Trocar o número de suporte (SUPORTE_WHATSAPP) em src/lib/config.ts pelo WhatsApp real do Super Admin (hoje é um número fictício).
