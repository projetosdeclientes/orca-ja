# Orçamento Rápido

Este é o projeto OrçaJá, um gerador de orçamentos por medidas para pequenas empresas, multi-empresa e em português do Brasil. Ainda não vou passar as instruções de construção. NÃO crie nem altere nenhum arquivo agora e não instale nada. Responda apenas "Pronto, aguardando as instruções." e espere as próximas mensagens.
